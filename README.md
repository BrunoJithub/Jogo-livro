# Jogo-livro
🌌 Star Wars - Aventura em C++

Um jogo interativo em C++ baseado no universo de Star Wars, onde o jogador toma decisões que influenciam diretamente o rumo da história.

🚀 Sobre o Projeto

Este projeto consiste em uma narrativa interativa desenvolvida em C++, onde o jogador assume o papel de um Jedi Rebelde em uma missão perigosa.

- Durante a jornada, o jogador poderá:

- Escolher caminhos diferentes
- Enfrentar inimigos
- Tomar decisões estratégicas
- Participar de combates com sistema baseado em dados (d6 🎲)

- Cada escolha pode levar à vitória… ou ao GAME OVER.

🧠 Conceitos Utilizados

- Este projeto aplica diversos conceitos fundamentais da programação:

- Estruturas condicionais (if/else)
- Funções (void, retorno)
- Estruturas de repetição (while)
- Geração de números aleatórios (rand())
- Manipulação de entrada/saída (cin / cout)
- Organização de código em múltiplas funções
- Simulação de combate com lógica probabilística

  
🎮 Como Jogar
- Compile o código em um compilador C++ (g++)
- Execute o programa
- Leia a história e escolha suas ações digitando as opções no terminal


⚔️ Sistema de Combate

- O combate funciona com base em rolagem de dados (d6):

- O jogador e o inimigo rolam um dado
- O resultado define ataque, defesa ou erro
- Estratégias:
- Atacar
- Defender
- Tomar decisões táticas

📁 Estrutura do Código

- O código é organizado em funções principais:

- main() → Início da história
- sinal() → Caminho alternativo (Destroyer Imperial)
- caverna() → Caminho principal (Orbe Ancestral)
- rolarDado() → Simulação de dado (1 a 6)

🛠️ Tecnologias Utilizadas
- C++
- Biblioteca padrão (iostream, cstdlib, ctime)
- Controle de tempo (thread, chrono)

💡 Destaques
- Narrativa imersiva estilo RPG
- Múltiplos finais
- Sistema de combate dinâmico
- Uso de delays para aumentar a imersão
- Estrutura modular do código
